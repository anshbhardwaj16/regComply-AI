Problem Statement

"Develop an agentic solution that understands regulatory requirements and how they change over time, assesses banks' internal control mechanisms, identifies gaps, and suggests appropriate remedies."

Why this problem?

  • Banks paid ~$321B in fines between 2008 and 2016 (BCG Global Risk 2017)
  • Manual gap analysis is slow and document-heavy; our pipeline does a first pass in one automated run
  • Regulations change constantly — change intelligence is table stakes
  • Perfect match for agentic AI: multi-step reasoning, traceable outputs

Our solution

regComply-AI: The Intelligent Compliance Chain

Banks upload regulations and internal control policies. Seven specialized agents analyze, map, score and remediate, producing a traceable compliance picture.

What makes it agentic

  • Each agent has a single, specialized role; its output feeds the next agent
  • Agents reason over structured JSON with confidence scoring
  • JSON recovery logic handles partial/malformed LLM outputs
  • Pipeline streams real-time progress via Server-Sent Events
  • Simulation agent reasons over hypothetical future scenarios
Compliance score (deterministic, computed from agent mappings)
score = (Full + 0.5 × Partial) ÷ Total × 100

Solution Output: one compliance intelligence report

  • Obligations with regulation references
  • AI-scored controls (0–100)
  • Full / Partial / None mapping + confidence
  • Risk-ranked gap register
  • Remediation: owner, timeline, effort
  • Board-level executive summary
  • Regulatory change impact analysis
  • What-if score projections

Three operating modes

ANALYZE Full 6-agent pipeline: obligations → controls → mapping → gaps → remediation
CHANGE Regulatory change intelligence: compare old vs. new regulation versions
SIMULATE What-if scenarios: model proposed regulations before they take effect

Scalability & Responsible AI

Built to Scale. Built to Be Trusted.

Scalability Architecture

  • Stateless FastAPI backend: scales horizontally behind a load balancer
  • SSE streaming: long pipelines run without HTTP timeouts
  • Async executor: LLM calls run in a thread pool; the event loop stays responsive
  • Independent analyses: no shared state between runs, so batch mode is a queue away
  • Long documents: next step is chunked retrieval to replace today's 8,000-character input cap

Responsible AI & Trust

  • Full traceability: every gap links to the exact obligation and control behind it
  • Confidence scoring: a 0–1 confidence per mapping, shown in the traceability view
  • Conservative prompting: agents prefer reporting a gap over force-fitting a match
  • Low temperature (0.1): OpenAI and Groq calls tuned for repeatable, schema-conformant output
  • Provider-switchable: OpenAI, Groq or Anthropic Claude via one env var
Hallucination Mitigation

Every agent is prompted for an exact JSON schema. Recovery logic salvages complete items from truncated output instead of guessing. Every mapping carries a confidence score.

Privacy & Security

Documents are processed in memory and nothing is persisted server-side. Text is sent only to the configured LLM provider; self-hosted models are on the roadmap for on-premises use.

Human Oversight

AI generates findings; humans validate. Every gap includes AI reasoning so compliance officers can verify or override the assessment.
